# 🎨 Modern Profile Card UI Design

A clean, modern and responsive **Profile Card UI Design** built using HTML and CSS.  
This project focuses on glassmorphism style, smooth hover animations, and modern UI design principles.

## ✨ Features

- 🎯 Modern glassmorphism UI design  
- 📱 Fully responsive layout  
- 🎨 Beautiful gradient background  
- ⚡ Smooth hover animations  
- 👤 Profile image section  
- 🔗 Social media icons integration  
- 💬 Action buttons (Message & Download CV)  
- 📊 Stats section (likes, comments, shares)  
- 🧠 Clean and beginner-friendly code structure  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Font Awesome Icons  
- Google Fonts (Inter)

---

## ⚙️ How to Run This Project

1. Download or clone the repository  
2. Open the project folder  
3. Run `index.html` in your browser  
4. Done ✔️
